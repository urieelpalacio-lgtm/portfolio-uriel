# Portfolio personal – Uriel Palacio

Portfolio web personal desarrollado con HTML5 y CSS3. Presenta intereses y experiencias escolares vinculadas con informática, electrónica, producción audiovisual y automovilismo.

## Estructura de archivos
- `index.html`: estructura y contenido del sitio.
- `css/estilos.css`: estilos visuales, navegación y adaptación a pantallas pequeñas.
- `bitacora_ia.md`: registro del uso de inteligencia artificial.

## Proyectos destacados
1. **ConvivIA:** trabajo escolar con Python, Tkinter, SQLite y arquitectura MVC. Se describe la participación en la comprensión de la estructura y las pruebas CRUD.
2. **Arduino y sensores:** exploración de conexiones y alimentación de un sensor de distancia y motores.
3. **Edición audiovisual:** planificación de capas de audio, selección de efectos y sincronización con un fragmento de video.

Las descripciones distinguen las actividades de aprendizaje de los productos terminados y no afirman resultados que no hayan sido confirmados.

## Mejoras aplicadas
- **Funcionamiento y adaptación:** navegación con enlaces internos a cada sección, desplazamiento suave, estados de foco visibles para teclado y diseño responsive para celulares y tabletas.
- **Contenido y diseño:** presentación actualizada a nombre de Uriel Palacio, selección de tres proyectos con el apartado «Mi aporte» y una identidad visual oscura con detalles rojos.

## Publicación en GitHub Pages
En el repositorio, abrir **Settings → Pages** y seleccionar **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guardar y esperar a que GitHub genere la dirección pública.

## Comprobaciones antes de entregar
- Abrir la URL publicada en una ventana privada.
- Probar los enlaces del menú y el botón de proyectos.
- Revisar la presentación en computadora y celular.
- Confirmar que no se publiquen datos personales privados.
